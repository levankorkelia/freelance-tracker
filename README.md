# Freelance Tracker — ფრილანსერის დროისა და პროექტების აღრიცხვა

კონსოლური აპლიკაცია, რომელიც ფრილანსერს ეხმარება აღრიცხოს კლიენტები,
პროექტები და თითოეულ პროექტზე დახარჯული სამუშაო საათები, შემდეგ კი
მიიღოს ანგარიში შემოსავლის გამოთვლით და ვიზუალური გრაფიკები.

## Description

პროექტი წყვეტს კონკრეტულ ამოცანას: ფრილანსერი ერთდროულად რამდენიმე კლიენტთან
მუშაობს და ხშირად ზუსტად არ იცის, რომელ პროექტს რამდენი დრო მოახმარა და
რამდენი გამოიმუშავა. Excel-ის ცხრილი სწრაფად ირევა, ხოლო მზა SaaS
სერვისები ზედმეტად რთული და ფასიანია.

აპლიკაცია ინახავს მონაცემებს SQLite ბაზაში, გამოთვლის შემოსავალს
საათობრივი ტარიფის მიხედვით და ქმნის ორ გრაფიკს: პროექტების შედარებას და
თვეების მიხედვით დატვირთვის დინამიკას.

## Features

- კლიენტების დამატება, ნახვა და წაშლა
- პროექტების მართვა — თითოეული პროექტი კლიენტს უკავშირდება და საკუთარი საათობრივი ტარიფი აქვს
- სამუშაო საათების ჩაწერა თარიღისა და კომენტარის მითითებით
- ანგარიში პროექტების მიხედვით: საათები, შემოსავალი და საერთო ჯამი
- თვიური ანგარიში ტექსტური დიაგრამით
- ორი გრაფიკი PNG ფაილად: საათები პროექტების მიხედვით და დატვირთვის დინამიკა
- შეყვანილი მონაცემების ვალიდაცია: თარიღის ფორმატი, საათების დასაშვები დიაპაზონი, რიცხვითი ველები
- დაკავშირებული ჩანაწერების ავტომატური წაშლა (`ON DELETE CASCADE`)

## Technologies

- **Python 3.10+**
- **sqlite3** — მონაცემთა ბაზა (Python-ის სტანდარტულ ბიბლიოთეკაშია, ცალკე დაყენება არ სჭირდება)
- **matplotlib** — გრაფიკები
- **pytest** — ტესტირება

## Installation

```
git clone https://github.com/<your-username>/freelance-tracker.git
cd freelance-tracker
pip install -r requirements.txt
```

სასურველია ვირტუალური გარემოს გამოყენება:

```
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
```

## How to Run

```
python main.py
```

გაშვებისას გამოჩნდება მენიუ. აირჩიე პუნქტის ნომერი და დააჭირე Enter.

პირველ გაშვებაზე ბაზის ფაილი `data/tracker.db` ავტომატურად იქმნება —
წინასწარი მომზადება არ არის საჭირო.

### გამოყენების თანმიმდევრობა

1. `1` — დაამატე კლიენტი
2. `4` — დაამატე პროექტი და მიუთითე საათობრივი ტარიფი
3. `7` — ჩაწერე ნამუშევარი საათები (თარიღზე Enter ნიშნავს დღევანდელს)
4. `10` — ნახე ანგარიში შემოსავლით
5. `12` — შექმენი გრაფიკები; ისინი შეინახება `charts/` საქაღალდეში

### სტრუქტურის ლოგიკა

თითოეულ ფაილს ერთი გასაგები პასუხისმგებლობა აქვს. `main.py` მხოლოდ
მომხმარებელს ესაუბრება, `src/`-ის მოდულები კი ეკრანზე არაფერს ბეჭდავენ —
ისინი მონაცემებს აბრუნებენ. სწორედ ამის წყალობით შესაძლებელია
ანგარიშების ტესტირება და იმავე გამოთვლების გამოყენება გრაფიკებისთვის.
